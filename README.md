# interactive-todo-app-task3
A responsive Interactive To-Do App built using HTML, CSS, and JavaScript with dark mode and dynamic DOM manipulation.
 ## 🚀 Features

- Add Tasks
- Delete Tasks
- Mark Tasks as Completed
- Dark Mode Toggle
- Responsive Design
- Dynamic DOM Manipulation

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript

## 📚 What I Learned

- JavaScript Basics
- DOM Manipulation
- Event Handling
- User Interaction Design
